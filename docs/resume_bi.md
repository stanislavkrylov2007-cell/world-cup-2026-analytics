# Формулировки для резюме BI Developer

**World Cup 2026 Analytics — учебный BI-проект**  
Python · Pandas · PostgreSQL · SQLAlchemy · SQL · Streamlit · Pytest

- Реализовал ETL для данных о 49 520 международных футбольных матчах: проверка и стандартизация CSV, загрузка в PostgreSQL через SQLAlchemy с транзакциями и защитой от повторной загрузки одного файла.
- Разработал три SQL-витрины PostgreSQL с CTE, агрегациями и оконными функциями DENSE_RANK и SUM OVER: факты матчей, годовые показатели команд и динамика матчей.
- Создал Streamlit-дашборд с KPI, фильтрами по периоду, команде, турниру, стране и типу поля; добавил минимальный размер выборки для рейтинга и выгрузку результатов в CSV. Проверил расчёты и загрузку данных автоматическими тестами.

## Чем подтверждается

- Объём: `data/interim/matches_standardized.csv` — 49 520 строк; проверка не выявила полных дублей и пропущенных счетов.
- ETL: `src/world_cup_analytics/data/` и `database/load_matches.py`. Защита загрузки действует по имени исходного файла, а не по произвольному уникальному ключу матча.
- SQL: `sql/ddl/002_create_bi_marts.sql`; проверки — `tests/bi_marts_assertions.sql`.
- BI-панель: `dashboard/app.py` и `dashboard/data.py`; тесты — `tests/test_bi_dashboard.py`.

Это описание учебного проекта, а не коммерческого опыта. Время обработки, ускорение запросов, количество пользователей и влияние на бизнес не измерялись и в формулировки не включены.

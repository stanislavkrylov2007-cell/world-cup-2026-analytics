# Подтверждение BI навыков

Python · Pandas · SQLAlchemy · PostgreSQL · SQL · ETL · Pytest.

SQL-витрины: `bi_match_facts`, `bi_team_year`, `bi_year_trends`.
Конфигурация Redash, автоматическая загрузка данных и создание дашборда находятся в `deploy/redash`.
Указывать Redash как выполненный проект в резюме следует после успешного запуска `start-redash.cmd` и проверки графиков в браузере.

# Transformation Rules

## Purpose of `data/interim`

Слой `data/interim` нужен для воспроизводимого промежуточного датасета, который уже приведён к внутреннему контракту проекта, но ещё не является финальным аналитическим слоем.

## Difference Between `raw`, `interim`, and `processed`

- `data/raw` содержит исходные файлы пользователя без изменений.
- `data/interim` содержит стандартизированные промежуточные файлы с прозрачными и ограниченными правилами преобразования.
- `data/processed` предназначен для более поздних аналитических наборов данных, когда появятся SQL, EDA и feature engineering.

## Allowed Transformations

- Явное переименование столбцов по mapping-файлу.
- Удаление пробелов по краям строковых значений.
- Преобразование `date` в datetime.
- Преобразование `home_score` и `away_score` в целые числа только если у значений нет дробной части.
- Нормализация `neutral` в nullable boolean по заранее определённому списку значений.
- Добавление отсутствующих необязательных столбцов со значением `NA`.
- Выбор только столбцов внутреннего контракта.
- Упорядочивание столбцов по внутреннему контракту.

## Forbidden Transformations

- Угадывать соответствия столбцов.
- Исправлять названия команд.
- Объединять команды с похожими названиями.
- Заполнять пропущенные обязательные значения.
- Менять счёт матча.
- Удалять дубликаты.
- Удалять некорректные строки.
- Исправлять даты.
- Вычислять недостающие данные.
- Перезаписывать готовый результат без явного разрешения `--overwrite`.

## Neutral Rules

Поддерживаемые значения `True`:

- `true`
- `1`
- `yes`
- `y`
- `neutral`

Поддерживаемые значения `False`:

- `false`
- `0`
- `no`
- `n`
- `home`

Правила:

- сравнение нечувствительно к регистру и пробелам;
- пропуски сохраняются как missing;
- неизвестные значения не угадываются;
- неизвестные значения превращаются в `NA` с предупреждением без раскрытия самих значений.

## Reasons to Refuse Saving

Промежуточный CSV не сохраняется, если:

- отсутствует mapping-файл;
- в mapping не хватает обязательных соответствий;
- mapping ссылается на отсутствующий исходный столбец;
- score нельзя безопасно привести к целому числу;
- итоговая таблица не проходит существующую валидацию;
- целевой файл уже существует и не указан `--overwrite`.

## Overwrite Rules

- По умолчанию существующий файл в `data/interim/` не перезаписывается.
- Для явной замены нужно использовать `--overwrite`.
- Запись стандартизированного CSV выполняется атомарно: сначала временный файл, затем замена целевого.

## Limitations of This Stage

- На этом этапе не нормализуются команды, турниры, города и страны.
- Нет загрузки в PostgreSQL.
- Нет EDA, статистики, ML и дашборда.
- Преобразование зависит от ручного mapping-файла и не пытается “угадывать” структуру источника.

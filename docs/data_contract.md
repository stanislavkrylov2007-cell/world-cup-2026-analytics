# Data Contract

Этот документ описывает внутренний ожидаемый формат CSV-файла для ручной загрузки матчей в проект `World Cup 2026 Analytics`.

Это не официальная схема какого-либо конкретного внешнего источника данных. Это рабочий контракт текущего этапа проекта, который нужен для понятной ручной загрузки и первичной проверки качества данных.

## Columns

| Column | Назначение | Тип данных | Обязательное | Допустимые значения | Примеры некорректных данных |
|---|---|---|---|---|---|
| `date` | Дата матча | `datetime64[ns]` после загрузки | Да | Корректная дата матча, не пустая | `not_a_date`, пустое значение |
| `home_team` | Название домашней команды | string | Да | Непустая строка | пустая строка, `None`, совпадает с `away_team` |
| `away_team` | Название гостевой команды | string | Да | Непустая строка | пустая строка, `None`, совпадает с `home_team` |
| `home_score` | Голы домашней команды | integer | Да | Целое неотрицательное число | `-1`, `1.5`, `abc` |
| `away_score` | Голы гостевой команды | integer | Да | Целое неотрицательное число | `-2`, `0.7`, `abc` |
| `tournament` | Название турнира | string | Да | Непустая строка | пустая строка, `None` |
| `city` | Город проведения матча | string | Нет | Любая строка или пустое значение | строка из одних пробелов |
| `country` | Страна проведения матча | string | Нет | Любая строка или пустое значение | строка из одних пробелов |
| `neutral` | Признак нейтрального поля | boolean-like | Нет | `true`, `false`, `1`, `0`, `yes`, `no` и их булевы аналоги | `maybe`, `unknown` |

## Error Checks

Следующие проверки относятся к ошибкам и делают датасет невалидным:

- DataFrame пустой.
- Отсутствуют обязательные столбцы.
- В обязательных полях есть пропуски.
- Колонка `date` не преобразована в datetime.
- В `date` есть некорректные значения после преобразования.
- `home_score` или `away_score` не являются целыми неотрицательными числами.
- `home_team` совпадает с `away_team`.

## Warning Checks

Следующие проверки относятся к предупреждениям и не блокируют загрузку сами по себе:

- Отсутствуют необязательные столбцы.
- Есть дубликаты строк.
- После удаления пробелов встречаются пустые строковые значения.
- Есть подозрительно большие значения счёта.
- Есть даты в будущем.
- В `neutral` встречаются неизвестные значения.

## Notes

- На этом этапе программа не исправляет данные автоматически.
- Строки не удаляются автоматически, даже если в них есть проблемы.
- Если будущий реальный источник данных будет иметь другую схему, этот контракт можно будет обновить отдельно.
